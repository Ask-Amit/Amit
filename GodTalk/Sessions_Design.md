# GodTalk - Design and tables

Read the section "## Tables" first when you only need the database tables. The other sections describe how the project is built; read them only when working on that part.

## Tables
GodTalk has no database tables of its own.

## Structure
- `GodTalk\CLAUDE.md` holds the purpose and how a God Talk session works.
- Each topic is a folder inside `GodTalk\`, named in plain words, holding that topic's notes. The folder is created when Ryan answers "What are we talking about today?", and the session is titled with the same name.
- Finished topics go to the Devotions page only when Ryan says yes (Devotions has its own workflow).
