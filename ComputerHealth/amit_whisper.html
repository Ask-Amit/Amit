What this is

This is the speech recognition that lets Amit hear what you say. With it you can speak to any program on your computer: a message box, a web address bar, a search box, your code editor — anywhere you can type.

How to use it

  1. Click where you want the words to go (or just hold the button over that box).
  2. Hold the right mouse button until the small box next to your pointer says “Amit is listening”.
  3. Speak. Your words appear as you talk, and Amit tidies them up when you finish a sentence.
  4. Let go. (If “Press Enter when I let go” is on below, Amit also presses Enter to send.)

A quick tap of the button is still a normal click, so nothing else changes.

While you hold the button, your voice goes to your browser’s speech service — the same one Amit’s chat uses. Amit does not record or keep your voice. You can leave this window minimized.

Keep Whisper mode ready:
While Whisper mode is ready, it keeps a small window running in the background so it can start listening at once. That window uses about 400 MB of your computer’s memory (RAM) — up to about half a gigabyte — for as long as it stays on. If you keep it running all day, that memory is in use all day. Turning it off frees the memory; the next time you use it, it takes a few seconds to get ready.
