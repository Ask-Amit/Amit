Fix it, quiet it, or remove Amit

One page, three choices, on your Windows computer. You decide. Nothing happens until you press the button.
Open this page on the computer where Amit is installed (or scan the code with your phone and send the link to that computer):
ask-amit.github.io/Amit/AmitFix/AmitFix.html

1. Something is not working

  1. Open the page above and press the button that says what is happening ("Voice typing isn't typing", "It feels slow", and so on).
  2. Press Call it: download my fix. A small file called Amit_Fix.cmd lands in your Downloads.
  3. Double-click it. A black window shows what it is doing and checks its own work at the end.

2. I'd like Amit quieter

  • Turn voice typing off: nothing listens, and your mouse works exactly as normal.
  • Don't start with Windows: Amit opens only when you open it.
  • Each of these can be undone with its partner button.

3. I'm done with Amit

  1. Open the page, go to the last tab, Wrap.
  2. Press Download Remove-Amit.exe and open it. It asks once, then closes Amit's programs, turns off start-with-Windows, removes its shortcuts, deletes its files and saved data, and checks that it is really gone.
Left alone on purpose: your documents, the AmitInbox folder if you made one, your online Amit account, Claude, Node.js, Edge and Chrome.
If Windows says "unknown publisher", that is only because we have not bought a code-signing certificate yet. Choose More info → Run anyway. The whole program is a readable text file on the page ("What's On My Computer").

Updating Amit

If a problem will not go away, the surest fix is a fresh start: remove Amit as above, then install the newest version from the page ("Fresh start"). No manual steps.
We made Amit to walk alongside you. If you are leaving, we are sorry to see you go, and thank you for trying it. If something went wrong, that is on us. Please come back. The door stays open.
