Step 1: name this mouse
Type one word that you will recognize and say (for example Gaming or Office), then press Save name. After that, press every button on this mouse, then press Finished.
Before you start
Leave every button on your mouse the way it is now. If your mouse came with its own program, don't change its buttons there. Everything is set up right here instead. If something about your mouse changes later, come back to this tab and adjust it.
Why: your mouse's own program changes a button before Windows, and this program, ever see it. A button it has changed or keeps for itself can't be seen here. Use that program for lighting and speed (DPI), not for the buttons you want to set here.

Your sets

Switching sets

Any time, in any program: from a mouse button set to Switch mouse set, from a Helper bar button, or by voice: say "mouse" and the mouse's one-word name (that always means Set 1), or add "set" and a number, for example "mouse gaming set two". Any set can be moved to a free number, so deleting one never leaves a gap you cannot fill.
Reminder: keep your mouse's own program set the way it was. Everything is set here, and if something changes, come back to tab 1 and adjust.

What this page cannot do yet. The real program notices by itself which mouse you have just started using (after about a second of use, so an accidental bump does not switch) and switches to that mouse's setup; here you pretend with the box at the top. The real program watches the mouse across the whole computer (a browser only sees this box), hears your voice for "mouse" plus a set's name, and really sends the keys and clicks to the other program. A button that the mouse's own program changes or keeps for itself (a DPI button, say) may never reach Windows, so learning will not see it; that is why the screen asks people to leave the mouse's own program as it is, and a button that stays dashed is one Windows never received. Holding and double-clicking are timed here by your real press and release, so you can feel the delays; a button that has a double-click action must wait a moment before a single click acts, so a double-click action on a left button feels slower. On your primary mouse the left and right buttons never change, so Amit always works; on any other mouse they can be changed. Changing the left button of a second mouse needs the real program to tell the mice apart at the very moment of the click, which has to be tested on your computer before anyone relies on it, and "Mouse sets are off" is also in the tray so a bad setting can never trap you.
