What to know. The Amit Helper on this computer watches every keyboard through Windows, tells them apart, and applies the sets everywhere on the computer. Windows keeps a few keys for itself (Ctrl+Alt+Delete, Win+L, Alt+F4). A key with a double-press action has to wait a moment before a single press acts. A key that is part of a pair waits a moment too, so the pair can be told from two single keys; it is typed the instant you let go or press anything else. Holding Space for 400 ms then pressing a number switches sets: a Space held that long and let go on its own still types one space. Auto-repeat, AltGr, dead keys and input methods are worth trying on your own keyboards. This page cannot see the Windows key or the Fn key by itself; the Helper sees the Windows key. A keyboard that handles a key before Windows sees it (a Fn key, say) cannot be changed here.
Scrambled, not secure. A Code keeps a message from casual eyes. A determined person with a computer can break a code like this (the Enigma machine was broken). For real privacy, real encryption goes underneath; that is a separate step and is not built.
How a Code works
Each of your keyboard sets (not Set 1) is a scramble table: in Set 4, G types Q, and so on. EVERY key can be scrambled, not only letters: Space is not necessarily a space (in a set, M can type the space and the Space key can type a letter), and a combination such as Ctrl+G or a pair of keys held together can be a symbol of its own. Some keys also say "type this, then switch to Set N" (set it on the Keyboard sets tab: Send keys, then switch set). So the table changes as you type, and the next letter is scrambled by a different set. To read the message, the other person needs the same sets: they follow the same switches and arrive at the same set for every letter.
Rules that make a message readable: every scramble set must be one-to-one (no two keys type the same character, a space counts as a character), and every key that switches must also type something, because the reader can only see the letters, not the switches. The checks below look for both.

Scrambled, not secure. The modifiers add a private layer on top of the sets: the keyboard sets can be shared with anyone, but the secrets below stay between the two of you. It still does not make this real encryption. A birthday or a date can be guessed by trying them all, and stacking several simple shifts adds less than it feels like. A long secret that nobody could guess helps more than more steps do.
How a modifier works
You and the other person agree on a secret that only you two know (today's date, a birthday, a word, a number). Amit turns it into a number by adding up the ASCII codes of its characters (A is 65, B is 66, 0 is 48, and so on). Then it changes every character of the code from the Secret code tab by that number: add it, subtract it, multiply by it, or add it plus one more for each place along the message. You can use up to four modifiers, one after another. The receiver needs the same keyboard sets AND the same modifiers, in the same order, to read the message on the Secret decipher tab.
The code characters are the 38 symbols A to Z, 0 to 9, space and #. A shift wraps around from the end back to the start. Multiplying only works with a number that has no common factor with 38, so if your number does not, Amit uses the next number up that does (the receiver's Amit does the same).
