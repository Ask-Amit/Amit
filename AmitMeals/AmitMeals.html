Introduction
What AmitMeals Does

One loop, four steps: Household holds who's eating and what they like (and their calorie needs). Budget sets what you want to spend and where. Pantry tracks what's already on hand. Recipes holds meals with calories, cuisine, prep and storage instructions. Weekly Menu builds a week's plan sized to real portions per person. Shopping List turns that plan into what to actually buy — checking the pantry first, favoring bulk where it will actually get used, and showing projected cost against your budget.

Get Started
1. Add household members (Household tab) — this drives portion sizing.
2. Set your weekly budget and preferred spend split (Budget tab).
3. Add a few recipes your household actually eats (Recipes tab).
4. Build this week's menu and generate the shopping list.

Recipe Source API Keys

Keys are saved only in this browser's local storage — never written into the app's file, never pushed to GitHub. TheMealDB needs no key. Leave the field blank to skip Spoonacular.

Import Real Recipes

Pulls actual recipes — real ingredients, real step-by-step instructions — from TheMealDB (free, no key needed) and, once a key is saved above, Spoonacular too. Nothing here is written by Amit; it's the same instructions you'd get from a recipe book. Everything found lands in the Review queue below first — nothing joins the library until you accept it.

Review Before Adding to the Stock

Every source lands here first, not straight into the library. Accept the ones you want — they join the one combined Recipe Library below, same pool the Menu Generator draws from regardless of which source found it. Reject the rest.

Hard Rules — Always Applied

These apply to every generated menu, every week, automatically — no need to re-type them each time. Checked = excluded.

Individual Preferences — By Person

Every menu is scored against each person's own list, not one blended household guess. Anyone's hard dislike here excludes an ingredient from the whole week's menu, the same as a Hard Rule above — no re-typing it. Anyone's like gets that ingredient favored more often. Add household members on the Household tab first if the picker below is empty.

Rate Every Recipe

Go through the library once — 👍 Like / 👎 Dislike / — Skip. Liked recipes get favored, disliked ones are excluded from every future generated menu, the same as a hard rule above.

The Question Set

This searches your Recipe Library (page 5) — including anything imported from TheMealDB's real recipe database. Live grocery pricing isn't wired in yet, so costs stay at whatever's entered per recipe. Import some real recipes on the Recipes tab first if the library's empty. Answer these and the generator builds a full week within your numbers, pairing batch-cook meals with leftover days where it can.
