What This File Is

💻 Windows — Save & Open Locally

  1. Right-click the file link or this page and choose Save As → save as covenant_analysis.html anywhere on your computer (Desktop, Documents, etc.)
  2. Double-click the saved file — it will open in your default browser (Chrome, Edge, Firefox)
  3. The file works offline. Bookmark it in your browser for quick return access (Ctrl+D)
  4. To share: email the file as an attachment, or copy it to a USB drive — no server required

🍎 Mac — Save & Open Locally

  1. Right-click (or Control+click) the file and choose Download Linked File or Save As
  2. Open Finder → navigate to your Downloads folder → double-click the file to open in Safari, Chrome, or Firefox
  3. Drag the file to your Dock or add a browser bookmark (⌘+D) for quick access
  4. Mac may show a security prompt for locally-opened HTML files — click Open to proceed

📱 Mobile (iPhone / Android) — Save & Open

  1. iPhone: Tap and hold the file link → Download Linked File → opens in Files app. Tap to open in Safari. For repeated access, save a bookmark in Safari.
  2. Android: Tap and hold the link → Save Link → opens from your Downloads app in Chrome. Tap the three-dot menu → Add to Home Screen for a shortcut.
  3. Ask Amit at the bottom works on mobile — tap the input box and type your question normally
  4. For best mobile experience, use landscape orientation when viewing the Church Comparisons tab

🌐 Chrome & Edge — Bookmark or Install as App

  1. Open the file in Chrome or Edge
  2. Bookmark: Press Ctrl+D (Windows) or ⌘+D (Mac) → save to your Bookmarks Bar for one-click access
  3. Install as App (Chrome): Click the three-dot menu (⋮) in the top right → Save and share → Install page as app — this creates a standalone icon on your desktop or taskbar that opens the file like an application
  4. Install as App (Edge): Click the three-dot menu (…) → Apps → Install this site as an app
  5. Once installed as an app, it appears in your Start Menu (Windows) or Applications folder (Mac) and opens without browser chrome
